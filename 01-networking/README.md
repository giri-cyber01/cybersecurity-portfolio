## Labs

### 1. ICMP Packet Analysis with Wireshark

**Status:** In progress

**Objective:** Understand how ICMP Echo Request and Echo Reply packets work and how to inspect them in Wireshark.

**Tools:** Kali Linux, Wireshark, and ping.

**What I am learning:**
- How to capture network traffic.
- How to filter ICMP packets in Wireshark.
- How to identify source and destination IP addresses.
- How to inspect ICMP packet types and sequence numbers.

The detailed procedure, observations, and screenshots will be documented in a dedicated lab folder as I complete and verify them.
